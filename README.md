# Student Management System

A full-stack web application for managing student records with secure authentication and role-based access.

## 🚀 Live Demo

Frontend: https://student-management-system-mex3332mg-bro-code21.vercel.app

Backend: https://student-management-system-7jjx.onrender.com

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML
- CSS
- Axios
- React Router

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- Hibernate
- REST API
- Maven

### Database
- MySQL

### Deployment
- Vercel – Frontend
- Render – Backend
- Aiven – MySQL Database
- GitHub – Source Code

## ✨ Features

- User registration and login
- JWT-based authentication
- Role-based access control
- Admin and User roles
- Add student
- View students
- Update student
- Delete student
- Search students
- Responsive web interface
- Persistent MySQL database

## 🔐 Security

- JWT authentication
- Spring Security
- Role-based authorization
- Password encryption
- CORS configuration
- Stateless authentication
